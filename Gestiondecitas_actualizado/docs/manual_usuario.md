Sistema de Gestión de Citas

1. Introducción

El sistema de Gestión de Citas es una aplicación desarrollada en C# mediante Windows Forms. Su propósito es facilitar la administración de clientes y citas, ofreciendo una interfaz sencilla para realizar las operaciones del sistema.

2. Objetivo del sistema

Proporcionar una herramienta que permita gestionar la información de los clientes y organizar las citas de manera ordenada.

3. Requisitos para utilizar el sistema

- Computadora con Windows.
- Aplicación ejecutable del sistema.
- Entorno compatible con aplicaciones Windows Forms de .NET

4. Ingreso al sistema

Al ejecutar la aplicación, se muestra la pantalla principal del sistema de Gestión de Citas. En esta pantalla se presenta el acceso al módulo de registro de clientes.

5. Registro de clientes

Para registrar un cliente, el usuario debe:

1. Ingresar al sistema.
2. Seleccionar el botón Registrar en la pantalla principal.
3. Completar los campos solicitados:
   - Nombre del cliente.
   - Número de teléfono.
   - Correo electrónico.
4. Presionar el botón Registrar para guardar la información.

El sistema verifica que los campos estén completos y que el teléfono y el correo electrónico tengan un formato válido.

Si el registro es exitoso, se muestra un mensaje de confirmación y los campos se limpian para permitir un nuevo registro

6. Mensajes y validaciones

El sistema muestra mensajes para orientar al usuario durante el registro de clientes.

- Campos incompletos: se solicita completar todos los campos.
- Teléfono inválido: se indica que el número debe contener entre 8 y 15 dígitos.
- Correo inválido: se muestra un mensaje que solicita ingresar un correo electrónico con formato válido.
- Registro exitoso: se muestra un mensaje de confirmación cuando el cliente se registra correctamente.

7. Recomendaciones de uso

- Completar todos los campos antes de registrar un cliente.
- Verificar que el número de teléfono contenga únicamente dígitos.
- Revisar que el correo electrónico tenga un formato correcto.
- Leer los mensajes que muestra el sistema para corregir posibles errores.
