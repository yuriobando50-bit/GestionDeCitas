Gestión de Citas

Descripción

Gestión de Citas es una aplicación de escritorio desarrollada en C# con Windows Forms. Su propósito es facilitar la organización de la información de los pacientes y las citas.



Objetivo

Desarrollar una aplicación sencilla que permita organizar y consultar la información relacionada con los pacientes y las citas.

Tecnologías utilizadas

* Lenguaje de programación: C#.
* Interfaz gráfica: Windows Forms.
* Entorno de desarrollo: Visual Studio.
* Control de versiones: Git y GitHub.



Funcionalidades iniciales previstas

* Pantalla principal del sistema.
* Organización de la información de los pacientes.
* Gestión de citas.
* Validación de datos.

Estas funcionalidades se incorporarán progresivamente durante el desarrollo del proyecto.
