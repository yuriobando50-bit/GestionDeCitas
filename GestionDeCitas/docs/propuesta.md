Propuesta del proyecto: Gestión de Citas

3. Problema que se desea resolver
La gestión manual de citas puede dificultar la organización de la información, el seguimiento de las citas programadas y el acceso rápido a los datos de los pacientes. Esto puede provocar confusiones y pérdida de tiempo al consultar o actualizar la información.

El proyecto propone desarrollar una aplicación de escritorio que permita organizar la información relacionada con los pacientes y las citas de manera sencilla.

4. Justificación

El desarrollo de Gestión de Citas busca facilitar la organización de la información de los pacientes y las citas mediante una aplicación de escritorio sencilla. El sistema permitirá reducir la dependencia de registros manuales y facilitar la consulta y actualización de la información.

5. Usuarios

La aplicación está dirigida al personal encargado de registrar pacientes, organizar citas y consultar la información relacionada con la atención.

6. Objetivo general

Desarrollar una aplicación de escritorio en C# con Windows Forms que facilite la organización y gestión de la información de los pacientes y sus citas.

7. Objetivos específicos

- Crear una interfaz gráfica sencilla y fácil de utilizar.
- Permitir el registro y la consulta de información de los pacientes.
- Facilitar la organización de las citas.
- Incorporar validaciones para reducir errores en los datos.
- Utilizar Git y GitHub para organizar el desarrollo colaborativo.

8. Alcance

La primera versión incluirá una pantalla principal, formularios para gestionar la información, validaciones básicas y operaciones de registro, consulta y actualización de datos. La información podrá manejarse mediante listas o colecciones en memoria, según las necesidades de cada módulo.

9. Fuera de alcance

La primera versión no incluirá una base de datos permanente, integración con servicios externos, envío automático de recordatorios ni funciones de pago. Estas características podrán considerarse en futuras versiones si el alcance del proyecto lo permite.

10. Funcionalidades previstas

- Navegación desde el formulario principal.
- Registro y consulta de pacientes.
- Organización y consulta de citas.
- Validación de campos obligatorios y formatos.
- Presentación organizada de la información.
- Mensajes para informar al usuario sobre las operaciones realizadas.

11. Distribución inicial de tareas

- Integrante 1: estructura inicial del proyecto, documentación y configuración de GitHub.
- Integrante 2: desarrollo del módulo de registro de pacientes.
- Integrante 3: desarrollo del módulo de gestión de citas.
- Integrante 4: consultas y presentación de la información.
- Integrante 5: validaciones, pruebas e integración de los módulos.

La distribución es inicial y podrá ajustarse de común acuerdo entre los integrantes.
